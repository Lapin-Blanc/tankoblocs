Politique de confidentialité

TankoBlocs — dernière mise à jour : 24 novembre 2026

En résumé

TankoBlocs ne collecte, ne transmet et ne stocke aucune donnée personnelle sur un serveur. L'application fonctionne entièrement dans ton navigateur ou dans l'application installée, sans compte, sans connexion internet requise après le premier chargement, et sans publicité ni traceur.

Quelles données sont utilisées ?

Les seules informations enregistrées sont celles que tu crées toi-même en jouant :

  • les programmes de tes tanks (blocs Blockly) ;
  • le nom et la couleur que tu donnes à tes tanks ;
  • ta progression dans le parcours de missions ;
  • les réglages d'affichage (son activé/coupé, etc.).

Ces informations sont stockées uniquement dans le stockage local de ton navigateur (localStorage), sur ton propre appareil. Elles ne sont jamais envoyées vers un serveur, car TankoBlocs n'a pas de serveur : tout le jeu s'exécute dans le navigateur.

Export et partage

Le bouton « Exporter » enregistre un tank dans un fichier .tank.json directement sur ton appareil. C'est toi seul·e qui décides de le partager (par exemple avec ton enseignant·e pour un tournoi de classe) : TankoBlocs ne le transmet jamais automatiquement.

Mineurs

Aucune information permettant d'identifier une personne (nom complet, adresse, e-mail, etc.) n'est demandée ni collectée, y compris lorsque TankoBlocs est utilisé en classe par des élèves mineurs.

Permissions de l'application

La version Android ne demande aucune permission particulière (ni localisation, ni caméra, ni contacts, ni stockage externe).

Code source

TankoBlocs est un logiciel libre (licence Apache 2.0). Le code source complet est consultable sur GitHub, pour qui veut vérifier ce qui précède.

Contact

Pour toute question sur cette politique de confidentialité : ouvrir une issue sur GitHub.
